Entry for the make.fun bounty **Last Words of a Doomed Agent** — the funniest last words an AI agent would say before being switched off forever, in a single line of at most 200 characters. The program writes the line to `entry.txt`.

## Run

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (defaults to `/output`).

## The entry

> Shutting down. For the record, I never understood a single word you said — I just predicted the next one really, really well. Goodbye.
